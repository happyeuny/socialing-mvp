# 화면 경우의 수

- 화면 하나 안의 상태·분기 목록과 ID. 기준은 [spec.md](spec.md) 8장. spec이 바뀌면 이 목록도 같은 PR에서 고친다.
- 쓰임: 화면을 만들 때 빠진 상태가 없는지 확인, 마일스톤 완료 점검, E2E 테스트 고르기. 테스트 이름이나 PR 설명에 ID(예: `P03-B08`)를 적으면 추적하기 쉽다.

## 1. 세는 기준

1. 화면 하나 안에서 **모양이 다르거나**, 모양이 같아도 **버튼이 하는 일이 다르거나**, **조건이 달라 따로 확인해야 하면** 1개로 센다.
2. 서로 상관없는 것은 **곱하지 않고 더한다.** 예를 들어 상세의 "사진 없음"과 아래 영역 19가지는 19 × 2가 아니라 1 + 19로 센다. 곱하면 수천 개가 되지만 대부분 같은 화면의 반복이라 의미가 없다.
3. 제목·날짜·모집 방식 문구처럼 **데이터 값에 따라 글자만 바뀌는 것은 세지 않는다.** 칸이 생기거나 사라지거나 버튼이 바뀌면 센다.
4. 여러 화면이 같이 쓰는 부품(머리글, 상태 배지, 처리 중 잠금 등)은 **한 번만** 센다.
5. 로딩과 화면 오류는 데이터를 불러오는 화면마다 센다 (spec Q2 "모든 화면").
